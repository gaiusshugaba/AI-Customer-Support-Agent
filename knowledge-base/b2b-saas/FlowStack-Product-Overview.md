## What is FlowStack?

FlowStack is a B2B SaaS workflow automation platform. Teams use it to connect business systems, automate repetitive work, monitor executions, and collaborate inside shared workspaces. It runs entirely in the cloud and requires no on-premise installation.

## What can you build with FlowStack?

You can build multi-step workflows that trigger on events (like a new order, a form submission, or a schedule), take actions in connected systems (like creating a record, sending an email, or posting to a webhook), and branch on conditions. Workflows can call external APIs, transform data, and chain multiple integrations in sequence.

## What are the core features?

- Workflow automation with triggers, actions, conditions, and loops
- Execution history showing every run, its status, and its output
- Team workspaces with role-based access control
- Usage and plan limits with per-workspace metering
- Integration credentials and connection management
- REST API access for programmatic workflow operations
- Webhook triggers for inbound events
- Audit logging for administrative actions

## What integrations does FlowStack support?

FlowStack supports over 200 integrations across categories including CRM (Salesforce, HubSpot), email (Gmail, Outlook), messaging (Slack, Teams), storage (Google Drive, Dropbox), databases (PostgreSQL, MySQL), and generic HTTP/REST endpoints. Custom integrations can be built via the HTTP Request node or the public API.

## How do I get started?

Sign up at flowstack.com, create a workspace, and choose a plan. The Starter plan is free and requires no credit card. From the workspace dashboard you can create your first workflow, connect an integration, and test an execution. There's also a library of pre-built templates you can copy into your workspace.

## What browsers are supported?

FlowStack supports the latest two versions of Chrome, Firefox, Safari, and Edge. The admin dashboard does not support Internet Explorer. The API and webhook endpoints work with any HTTP client.

## Is there a mobile app?

There is no dedicated mobile app. The web dashboard is responsive and works on tablets and phones, but the workflow editor is only fully usable on desktop screens.

## Support principle

FlowStack support explains product behavior from the knowledge base, then uses customer account data when the question is account-specific. Support never invents a plan, limit, refund, outage, or account state.
